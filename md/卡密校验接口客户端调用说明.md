# 卡密校验接口客户端调用说明

## 📋 接口信息

**接口地址：** `admin/card/pub/verify`

**接口类型：** 公开接口（无需登录）

**请求方式：** POST

## 🎯 核心功能

统一接口自动处理：

- ✅ **卡密激活**：首次使用时自动激活并设置过期时间
- ✅ **机器绑定**：自动绑定新机器，检查机器数量限制
- ✅ **状态校验**：验证卡密是否过期、次数是否用完

## 📝 请求参数

```javascript
{
  key: "ABCD-1234-EFGH-5678",      // 卡密码（必填）
  product_id: "product_001",       // 产品ID（必填）
  machineCode: "machine-001",      // 机器码（可选，取决于卡密是否限制机器数量）
  id: "user123"                    // 用户ID（必填）
}
```

### 参数说明

| 参数        | 类型   | 必填 | 说明                                                 |
| ----------- | ------ | ---- | ---------------------------------------------------- |
| key         | String | 是   | 卡密码                                               |
| product_id  | String | 是   | 产品ID（卡密所属产品）                               |
| machineCode | String | 否   | 机器码（设备唯一标识）。如果卡密限制机器数量，则必填 |
| id          | String | 是   | 用户ID（购买卡密的用户ID）                           |

## 📤 响应结果

### 成功响应（code: 0）

```javascript
{
  code: 0,
  msg: "卡密激活成功，机器绑定成功",  // 或 "机器绑定成功" 或 "校验成功"
  data: {
    // 基本信息
    card_id: "card_id_123",
    card_code: "ABCD-1234-EFGH-5678",
    card_type: "monthly",
    product_id: "product_001",
    product_name: "产品名称",

    // 激活和绑定状态
    is_activated: true,        // 是否本次激活
    is_new_machine: true,      // 是否新绑定机器

    // 时间信息
    has_time_limit: true,      // 是否有限制天数
    limit_days: 30,            // 限制天数（-1表示不限）
    activate_time: 1730678400000,           // 激活时间戳
    expire_time: 1733270400000,             // 过期时间戳

    // 次数信息
    has_times_limit: false,    // 是否有限制次数
    total_times: -1,           // 总次数（-1表示不限）

    // 机器码信息
    has_machine_limit: true,   // 是否有限制机器数量
    max_machine_count: 5,      // 最大机器数（-1表示不限）

    authorized_machines: [     // 已授权机器码列表
      "machine-001"
    ]
  }
}
```

### 失败响应（code: -1）

```javascript
{
  code: -1,
  msg: "错误信息"
}
```

### 常见错误信息

- `"请输入密钥"` - 未提供卡密码
- `"请传入用户ID参数（id）"` - 未提供用户ID
- `"卡密不存在或不属于该产品"` - 卡密码错误、产品ID不匹配或不存在
- `"此卡密不属于您，无法使用"` - 用户ID与卡密购买者不匹配
- `"卡密已过期"` - 卡密已超过有效期
- `"使用次数已用完"` - 卡密使用次数已用完
- `"此卡密需要提供机器码"` - 卡密限制机器数量但未提供机器码
- `"已达到最大授权机器数量"` - 卡密已绑定最大数量的机器

## 🔄 使用场景

### 场景1：首次激活（未使用的卡密）

**请求：**

```javascript
{
  key: "ABCD-1234-EFGH-5678",
  product_id: "product_001",
  machineCode: "machine-001",
  id: "user123"
}
```

**响应：**

- `is_activated: true` - 本次激活
- `is_new_machine: true` - 新绑定机器
- `activate_time` - 设置为当前时间
- `expire_time` - 自动计算（激活时间 + 限制天数）

### 场景2：绑定新机器（已激活的卡密）

**请求：**

```javascript
{
  key: "ABCD-1234-EFGH-5678",
  product_id: "product_001",
  machineCode: "machine-002",  // 新机器
  id: "user123"
}
```

**响应：**

- `is_activated: false` - 非本次激活
- `is_new_machine: true` - 新绑定机器
- `authorized_machines` - 包含新机器码

### 场景3：定期校验（已绑定的机器）

**请求：**

```javascript
{
  key: "ABCD-1234-EFGH-5678",
  product_id: "product_001",
  machineCode: "machine-001",  // 已绑定的机器
  id: "user123"
}
```

**响应：**

- `is_activated: false` - 非本次激活
- `is_new_machine: false` - 非新绑定机器
- `msg: "校验成功"`

### 场景4：超出机器数量限制

**请求：**

```javascript
{
  key: "ABCD-1234-EFGH-5678",
  product_id: "product_001",
  machineCode: "machine-011",  // 第11台机器（卡密限制10台）
  id: "user123"
}
```

**响应：**

```javascript
{
  code: -1,
  msg: "已达到最大授权机器数量"
}
```

## 💻 客户端集成示例

### JavaScript/Node.js

```javascript
/**
 * 卡密校验函数
 * @param {String} cardCode 卡密码
 * @param {String} productId 产品ID
 * @param {String} machineCode 机器码
 * @param {String} userId 用户ID
 * @returns {Promise<Object>} 校验结果
 */
async function verifyCard(cardCode, productId, machineCode, userId) {
  try {
    const response = await uniCloud.callFunction({
      name: 'router',
      data: {
        $url: 'admin/card/pub/verify',
        key: cardCode,
        product_id: productId,
        machineCode: machineCode,
        id: userId
      }
    })

    if (response.result.code === 0) {
      const data = response.result.data

      // 激活成功
      if (data.is_activated) {
        console.log('卡密激活成功！')
        console.log('激活时间：', data.activate_time_text)
        console.log('过期时间：', data.expire_time_text)
      }

      // 新机器绑定
      if (data.is_new_machine) {
        console.log('机器绑定成功！')
        console.log('当前已绑定机器数：', data.current_machine_count, '/', data.max_machine_count)
      }

      // 检查是否快过期
      if (data.has_time_limit && data.expire_time > 0) {
        const daysLeft = Math.ceil((data.expire_time - Date.now()) / (24 * 60 * 60 * 1000))
        if (daysLeft <= 7) {
          console.warn(`卡密将在 ${daysLeft} 天后过期，请及时续费`)
        }
      }

      return { success: true, data }
    } else {
      console.error('校验失败：', response.result.msg)
      return { success: false, error: response.result.msg }
    }
  } catch (error) {
    console.error('请求失败：', error)
    return { success: false, error: error.message }
  }
}

// 使用示例
const result = await verifyCard('ABCD-1234-EFGH-5678', 'product_001', 'my-machine-001', 'user123')
if (result.success) {
  console.log('授权验证通过')
} else {
  console.log('授权验证失败：', result.error)
}
```

### Python

```python
import requests
import json
from datetime import datetime

def verify_card(card_code, product_id, machine_code, user_id):
    """
    卡密校验
    :param card_code: 卡密码
    :param product_id: 产品ID
    :param machine_code: 机器码
    :param user_id: 用户ID
    :return: (success: bool, data: dict)
    """
    url = "https://your-domain.com/admin/card/pub/verify"

    payload = {
        "key": card_code,
        "product_id": product_id,
        "machineCode": machine_code,
        "id": user_id
    }

    try:
        response = requests.post(url, json=payload)
        result = response.json()

        if result['code'] == 0:
            data = result['data']

            if data['is_activated']:
                print('卡密激活成功！')
                print(f"激活时间：{data['activate_time_text']}")
                print(f"过期时间：{data['expire_time_text']}")

            if data['is_new_machine']:
                print('机器绑定成功！')
                print(f"当前已绑定：{data['current_machine_count']}/{data['max_machine_count']} 台机器")

            # 检查是否快过期
            if data['has_time_limit'] and data['expire_time'] > 0:
                days_left = (data['expire_time'] - int(datetime.now().timestamp() * 1000)) // (24 * 60 * 60 * 1000)
                if days_left <= 7:
                    print(f"警告：卡密将在 {days_left} 天后过期，请及时续费")

            return True, data
        else:
            print(f"校验失败：{result['msg']}")
            return False, result['msg']

    except Exception as e:
        print(f"请求失败：{e}")
        return False, str(e)

# 使用示例
success, data = verify_card('ABCD-1234-EFGH-5678', 'product_001', 'my-machine-001', 'user123')
if success:
    print('授权验证通过')
else:
    print(f'授权验证失败：{data}')
```

### C# / .NET

```csharp
using System;
using System.Net.Http;
using System.Text;
using System.Text.Json;
using System.Threading.Tasks;

public class CardVerifyService
{
    private readonly HttpClient _httpClient;
    private readonly string _baseUrl;

    public CardVerifyService(string baseUrl)
    {
        _baseUrl = baseUrl;
        _httpClient = new HttpClient();
    }

    public async Task<(bool Success, dynamic Data, string Error)> VerifyCardAsync(
        string cardCode,
        string productId,
        string machineCode,
        string userId)
    {
        try
        {
            var payload = new
            {
                key = cardCode,
                product_id = productId,
                machineCode = machineCode,
                id = userId
            };

            var json = JsonSerializer.Serialize(payload);
            var content = new StringContent(json, Encoding.UTF8, "application/json");

            var response = await _httpClient.PostAsync($"{_baseUrl}/admin/card/pub/verify", content);
            var responseText = await response.Content.ReadAsStringAsync();
            var result = JsonSerializer.Deserialize<JsonElement>(responseText);

            if (result.GetProperty("code").GetInt32() == 0)
            {
                var data = result.GetProperty("data");

                if (data.GetProperty("is_activated").GetBoolean())
                {
                    Console.WriteLine("卡密激活成功！");
                }

                if (data.GetProperty("is_new_machine").GetBoolean())
                {
                    Console.WriteLine("机器绑定成功！");
                }

                return (true, data, null);
            }
            else
            {
                var errorMsg = result.GetProperty("msg").GetString();
                Console.WriteLine($"校验失败：{errorMsg}");
                return (false, null, errorMsg);
            }
        }
        catch (Exception ex)
        {
            Console.WriteLine($"请求失败：{ex.Message}");
            return (false, null, ex.Message);
        }
    }
}

// 使用示例
var service = new CardVerifyService("https://your-domain.com");
var (success, data, error) = await service.VerifyCardAsync(
    "ABCD-1234-EFGH-5678",
    "product_001",
    "my-machine-001",
    "user123"
);

if (success)
{
    Console.WriteLine("授权验证通过");
}
else
{
    Console.WriteLine($"授权验证失败：{error}");
}
```

## 🔐 安全建议

### 1. 机器码生成

推荐使用以下信息组合生成唯一机器码：

- **Windows**:
  ```bash
  wmic bios get serialnumber
  wmic csproduct get uuid
  ```
- **Mac/Linux**:
  ```bash
  system_profiler SPHardwareDataType | grep "Serial Number"
  cat /sys/class/dmi/id/product_uuid
  ```
- **组合方式**: `MAC地址 + CPU序列号 + 主板序列号` 的哈希值

### 2. 校验频率

建议客户端软件：

- **启动时**：立即校验
- **运行中**：每1-2小时校验一次
- **网络恢复后**：立即校验

### 3. 离线容错

建议实现离线缓存机制：

- 校验成功后缓存授权信息
- 网络断开时使用缓存（设置有效期，如24小时）
- 超过离线容错期后强制在线校验

## 📊 字段说明

### 时间字段

- `limit_days: -1` 表示永久有效
- `activate_time: 0` 表示未激活
- `expire_time: 0` 表示未设置（未激活时）

### 次数字段

- `total_times: -1` 表示不限次数
- `remaining_times: -1` 表示不限次数
- `remaining_times: 0` 表示次数已用完

### 机器码字段

- `max_machine_count: -1` 表示不限机器数量
- `authorized_machines: []` 表示未绑定任何机器
- 新机器码会自动添加到 `authorized_machines` 数组中

## ✅ 接口特点

1. **三合一设计**：激活、绑定、校验统一处理，简化集成
2. **自动状态更新**：自动检测并更新过期状态
3. **机器数量管理**：自动限制机器绑定数量
4. **完整返回信息**：返回详细的授权信息供客户端使用
5. **无需登录**：公开接口，方便客户端调用

## 📝 注意事项

1. **用户ID验证**：确保传入的 `id` 参数与卡密的购买者ID一致
2. **机器码一致性**：确保同一台设备每次生成的机器码保持一致
3. **过期检测**：接口会自动检测并更新过期状态，已过期的卡密无法再使用
4. **机器数量限制**：超出限制后无法绑定新机器，可以通过管理后台查看已绑定机器列表
