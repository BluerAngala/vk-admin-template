# 卡密校验接口迁移指南

## 📋 接口变更概览

### 旧接口

- **地址**: `https://env-00jxtnydr3fv.dev-hz.cloudbasefunction.cn/user_obj/verifyAPIKey`
- **请求参数**: `{ collectionName: 'exe_apikey', id, key, machineCode }`
- **成功响应**: `{ code: 200, result: true, msg: '...' }`
- **失败响应**: `{ code: 400, result: false, msg: '...' }`

### 新接口

- **地址**: `https://env-00jxu65bfie3.dev-hz.cloudbasefunction.cn/http/router/admin/card/pub/verify`
- **请求参数**: `{ key, product_id, id, machineCode }`
- **成功响应**: `{ code: 0, msg: '...', data: {...} }`
- **失败响应**: `{ code: -1, msg: '...' }`

## 🔧 代码修改要点

### 1. 更新接口地址

```typescript
// 旧
const API_URL = 'https://env-00jxtnydr3fv.dev-hz.cloudbasefunction.cn/user_obj/verifyAPIKey'

// 新
const API_URL =
  'https://env-00jxu65bfie3.dev-hz.cloudbasefunction.cn/http/router/admin/card/pub/verify'
```

### 2. 更新请求参数

```typescript
// 旧
const payload = {
  collectionName: 'exe_apikey',
  id: userId,
  key: userKey,
  machineCode: uuid
}

// 新
const payload = {
  key: userKey, // 卡密码
  product_id: productId, // 产品ID
  id: userId, // 用户ID
  machineCode: uuid // 机器码
}
```

### 3. 更新响应处理

```typescript
// 旧
if (result.code === 200 && result.result) {
  // 成功处理
}

// 新
if (result.code === 0) {
  // 成功处理
  // result.data 包含详细信息（可选使用）
} else {
  // 失败处理（result.code === -1）
}
```

### 4. 统一返回格式（推荐）

**建议直接返回接口原始结果，保持数据一致性：**

```typescript
// 校验函数直接返回接口结果
export async function checkVIP(...): Promise<{ code: number; result: boolean; msg: string }> {
  const result = await fetch(API_URL, ...)
  const data = await result.json()

  // 统一返回格式
  if (data.code === 0) {
    return { code: 0, result: true, msg: data.msg || '校验成功' }
  } else {
    return { code: data.code || -1, result: false, msg: data.msg || '校验失败' }
  }
}

// IPC/API 层直接透传，不做格式转换
ipcMain.handle('login', async (_, loginId, loginKey) => {
  const result = await checkVIP({ vipUserId: loginId, vipUserKey: loginKey })
  // 直接返回，保持数据一致性
  return result
})

// 前端适配层做字段映射（如果需要）
const result = await window.api.login(loginId, loginKey)
const success = result.result === true
const message = result.msg || '登录失败'
```

## 📝 注意事项

1. **响应码变更**：成功从 `200` 改为 `0`，失败从 `400` 改为 `-1`
2. **字段名统一**：响应消息字段统一为 `msg`（不是 `message`）
3. **数据字段**：成功时返回的 `data` 字段包含卡密详细信息（可选使用）
4. **向后兼容**：如果前端需要 `success` 字段，在适配层做映射，不要修改核心校验函数
5. **产品维度校验**：必须传入 `product_id`，卡密将同时按密钥和产品维度匹配，避免跨产品误用
