# 3、框架更新步骤

**目前升级框架方式：**

### 方式一: 升级整个框架（包含模块）@mode1

> HBX 编译器版本需 `3.1.6`或更高

右键项目根目录下的 `package.json` 文件，再点击从【插件市场更新】

![输入图片说明](https://vkceyugu.cdn.bspapp.com/VKCEYUGU-cf0c5e69-620c-4f3c-84ab-f4619262939f/c764bee9-8fac-4fc6-80b7-e6d1a00740f5.png '插件更新方法.png')

**注意**

使用方式一更新框架是最方便的，但是如果你改动了框架内置的部分代码，你改动过的代码可能会被还原，因此如果你改动过框架内置代码，合并的时候，可以先看下改动的文件。

```js
如：
1、app.config.js
2、App.vue
3、main.js
4、pages.json
等等
升级前一定要进行文件对比！
```

### 方式二: 只升级模块@mode2

右键 `uni_modules/vk-unicloud/` 目录，再点击从【插件市场更新】

![](https://vkceyugu.cdn.bspapp.com/VKCEYUGU-cf0c5e69-620c-4f3c-84ab-f4619262939f/c72fa719-9444-4874-93a5-7b09d440feee.jpg)

### 注意事项

1. 更新后，需要在 `common/vk-unicloud` 右键上传公共模块才会生效
2. 若本次更新还涉及 router 内的函数更新，还需要再上传 router 函数
3. 若是本地调试模式，则需要重启本地服务才会生效。
4. 使用方式一更新时，你改动过的代码可能会被还原，因此如果你改动过框架内置代码，合并的时候，需要仔细对比差异。
5. 使用方式二更新框架不会造成你修改过的框架文件被覆盖，但是如果本次更新需要改动框架内一些文件，则需要你手动更改。
