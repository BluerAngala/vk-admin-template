# mytest — 临时测试云函数目录

存放开发调试中临时使用的云函数，用于数据库修复、数据迁移验证等一次性操作。

## 规范

- **只放临时/测试用途的云函数**，正式业务代码不要放这里
- 每个任务一个子目录，如 `fix-menu-sort/`、`init-categories/`
- 每个子目录必须有 `index.js`，遵循云函数标准结构
- 用完可保留（留作记录）或删除

## 使用方式

1. 在 HBuilderX 中右键子目录 → 上传并运行
2. 或通过 `vk.callFunction({ name: 'mytest/xxx', data: {} })` 调用

| 目录 | 用途 |
|---|---|
| `fix-menu-sort/` | 修正管理员菜单排序值（产品中心 1000、系统设置 1010、用户角色权限 1020） |
