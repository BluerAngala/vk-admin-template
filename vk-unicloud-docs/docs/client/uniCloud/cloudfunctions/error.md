# 全局错误码

## 框架错误码

| 错误码    | 说明                                              |
| --------- | ------------------------------------------------- |
| -1        | 默认的错误码                                      |
| 403       | 权限不足，拒绝访问                                |
| 404       | 请求路径不存在                                    |
| 405       | 逻辑停服：serviceShutdown 为 true 时              |
| 410       | 加密通信：该请求已失效                            |
| 411       | 加密通信：云端解密失败（请求参数不合法）          |
| 412       | 加密通信：客户端解密失败（响应体不合法）          |
| 413       | 加密通信：请求参数未加密 （请求参数不合法）       |
| 500 - 599 | 运行异常                                          |
| 30202     | token 无效：数据库已不包含此 token（uni-id 返回） |
| 30203     | token 无效：此 token 已过期（uni-id 返回）        |
| 30204     | token 无效：错误的 token（uni-id 返回）           |

注意：第三方接口的错误码均原样透传，不在此列举
