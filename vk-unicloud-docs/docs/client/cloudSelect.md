# uniCloud 云厂商选型指南

`uniCloud` 目前已对接 **3 家** 主流云厂商，按发布时序排序为：**腾讯云、阿里云、支付宝云**。

那么作为开发者，应该选择哪个云？或者说哪个云最适合我呢？

不废话，直接上结论：（以下结论非 uniCloud 官方观点，而是 vk 根据目前云开发用户反馈得出的结论）

**_注意：此结论会随着云厂商更新和用户最新反馈而动态调整，当前结论的日期为：2026 年 3 月 25 日_**

| 核心维度           | 对应选择              | 说明                                 |
| ------------------ | --------------------- | ------------------------------------ |
| 价格敏感型用户     | 支付宝云              | 性价比突出，适合所有项目一开始的首选 |
| 侧重稳定性用户     | 腾讯云                | 历史稳定性表现优异                   |
| 高性能与高可用兼顾 | 支付宝云 + 扩展数据库 | 综合表现最优，推荐中大型项目优先选择 |

**注意**：2026 年 3 月 25 日创建的支付宝云已经没有数据库语法兼容性问题了，支付宝云现在重回三云之首。

**综合排名（从性能、稳定性、开发体验分析）：**

| 排名      | 云厂商 + 数据库组合   | 说明                                                                      |
| --------- | --------------------- | ------------------------------------------------------------------------- |
| 1         | 支付宝云 + 扩展数据库 | 综合表现最优，推荐中大型项目优先选择                                      |
| 2         | 阿里云 + 扩展数据库   | 稳健可靠，适配多数业务场景，但性能不如支付宝云 + 扩展数据库               |
| 3（并列） | 支付宝云 + 内置数据库 | 性价比突出，适合所有项目一开始的首选（且还能 + 扩展数据库，登顶性能之首） |
| 3（并列） | 腾讯云 + 内置数据库   | 适合不想用扩展数据库，但对稳定性要求高的场景选择                          |
| 4         | 阿里云 + 内置数据库   | 因 2026 年 3 月 16 日之后，计费有保底消费，不适合新用户使用               |

**提示：当你的项目选择了一个云厂商后，并不是之后只能用这个云了，也是可以中途搬家换云的，这是 uniCloud 优势，比如等我项目日活高了，就换支付宝云+扩展数据库等，详见：** [数据库一键搬家工具，支持跨云搬家，跨账号搬家](../db-migration/README.md)
