# 11、云函数请求报跨域错误

**解决办法：**

将你用到的域名全部加入到 unicloud web 控制台的跨域白名单

如:

- 自己的域名 1
- 自己的域名 2

同时顺便把 localhost 也加入了

- localhost:8080
- localhost:8081
- localhost:8082
- localhost:8083
- localhost:3000
- localhost:3001
- localhost:3002
- localhost:3003

**现在可以直接加 \* 加入白名单了（代表对任何域名跨域）**

**步骤：**

- 1、 进入 unicloud web 控制台 https://unicloud.dcloud.net.cn/domain

- 2、 点击`跨域配置` - `新增域名`

- 3、 输入域名
